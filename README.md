# peoplex

株式会社PeopleXの採用スカウト運用で使うプロンプト・ドキュメントを管理するリポジトリです。

## プロンプト

- [`prompts/youtrust-scout-generation.md`](prompts/youtrust-scout-generation.md) — YOUTRUST候補者向けスカウトメッセージ生成プロンプト（判定基準・メッセージ設計・除外ルール・ブラウザ操作時の注意事項を含む）
- [`prompts/01_project-instructions.md`](prompts/01_project-instructions.md) — Claudeプロジェクト用の指示（スプレッドシートURLを貼るだけで除外チェック→求人相性判定→1通目生成→xlsx納品まで実行）
- [`prompts/02_integrated-rules.md`](prompts/02_integrated-rules.md) — 統合ルール集（スカウト生成v2＋スカウト相性チェッカー。01の細則としてプロジェクトナレッジに置く）
